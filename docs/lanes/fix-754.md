# #754: `discover_certificates` asks `{ identityKey }`

Base `c92ab842` (`origin/beta`'s tip at the lane's start, #752 landed: the
by-type questions' key and the recording facilitator this lane reuses).

## The reference

- The reference overlay at `ts-stack@edf6e03`,
  `packages/overlays/topics/src/identity/IdentityLookupService.ts:74-82`:
  the allowlist `attributes`, `certifiers`, `identityKey`,
  `certificateTypes`, `serialNumber`, `limit`, `offset`;
  `shared/queryValidation.ts:35-38`: any other own key refuses the whole
  question, `Invalid lookup query: unexpected field <key>`.
- `:144-145`: `identityKey` alone (no attributes, no types) answers
  `findByIdentityKey(identityKey, certifiers, ...)`;
  `IdentityStorageManager.ts:285-301` filters by certifier only when the
  list is present and nonempty.
- The reference wallet's `discoverByIdentityKey`
  (`wallet-toolbox` `Wallet.ts:966-1015`) asks
  `{ identityKey: args.identityKey, certifiers }` (`:1004`), the certifiers
  its trust settings' keys sorted by `localeCompare` (`:992`); the default
  settings name Metanet Trust Services and SocialCert
  (`WalletSettingsManager.ts:160-178`).

## The choice: no certifier

This crate has no trust settings; the wallet's trust step is unported
(#739's parity note). Its other by-key doors (`resolve_by_identity_key`,
`query`) name the SocialCert certifier alone. Naming it here would drop the
certificates of the reference's other default certifier, a narrowing the
door never had; naming none asks the overlay for every certifier's
certificate of the subject, the widest of the reference's admitted shapes,
and #739's subject filter still runs on the answer. So the question is
`{ identityKey }`.

## `certificatesOnly`

Written with the door by the identity module's original commit
(`5e4b9503`); `git log -S certificatesOnly` finds that commit, #739 and
#752 alone. Neither go-sdk@2ca481c nor ts-sdk sends it; no rustdoc,
README, `docs/` or changelog line describes it as a contract (the #739
parity note and #752's finding name it only as the difference). Removed
without a documented contract to retire; the semver note says so.
