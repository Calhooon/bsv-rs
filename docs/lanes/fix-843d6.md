## The decision as built

`pub struct SharedSecret` in `src/primitives/ec/shared_secret.rs`, one private
field (`point: PublicKey`), re-exported at `primitives::ec` and `primitives`
(where `PublicKey` is; the crate root re-exports neither name beside it, as
`Signature`'s siblings there are the common items alone). Public surface:
`to_compressed() -> [u8; 33]`, `x() -> [u8; 32]`, `to_point() -> PublicKey`
(each documented as revealing the secret); a hand-written `Debug`; `Clone`;
`PartialEq`/`Eq` in constant time (`subtle::ConstantTimeEq` over the
compressed bytes). `from_point` is `pub(crate)`. No zeroize: the rustdoc says
the point is not wiped on drop. `Schnorr::generate_proof` and `verify_proof`
keep `&PublicKey`; `PublicKey::mul_scalar` stays public, its rustdoc now a
true sentence (point arithmetic; with a private scalar the caller named
through `to_bytes`, the ECDH secret as a `PublicKey`).

## The fold (lane fix-843d6-fold, after three reads of PR #899, all accept)

Rebased onto beta `5618ae3b`. The decision's record is
`docs/design/843-identity-and-framing.md` section 9, items 6 to 8. Test-only, save
two doc-test blocks on the type; no line under `src/` changes behaviour.

- **The field's privacy, by the compiler.** A fifth `compile_fail` doc test
  builds `SharedSecret { point }` from outside the crate, and a compiling twin
  beside it holds the same lines without the struct expression. RED on a
  scratch copy with the field `pub` (and documented, since `missing_docs`
  refuses a bare one): `SharedSecret (line 62) - compile fail ... FAILED`,
  `Test compiled successfully, but it's marked compile_fail`.
- **The comparison.** `tests/shared_secret_bytes_843d6.rs`
  `two_different_pairs_are_unequal_and_one_pair_is_equal_both_ways_843d6`:
  three pairs, each equal through both doors and from both sides, each two
  unequal by `!=` and `==`, and a point unequal to its negation (the same x).
  RED with `eq` answering `true`: `pairs 0 and 1 compare equal`. The arch test
  refuses a derive of anything but `Clone` and wants the hand-written impl's
  body to call `ct_eq`: RED `line 75: a derived PartialEq` and `the impl of
  PartialEq does not call ct_eq`. A derived `PartialEq` is caught by the arch
  test alone (it compares correctly, in variable time).
- **The scan's spellings.** Every `pub` in the type's file is the type or,
  after `const`, `async`, `unsafe`, `extern` and an ABI string, a door's `fn`
  (`pub(` is a restricted visibility, passed over); `From`, `TryFrom`,
  `LowerHex`, `UpperHex` and `ToString` join the refused impls; the `fn`s
  returning `SharedSecret` are exactly the six of `SIX_DOORS`.
  `tests/secret_debug.rs` asserts the exact text, `SharedSecret { .. }`, plain
  and pretty, alone and inside a deriving struct: RED on a `Debug` writing
  y's base64, which the hex windows pass (`left: "SharedSecret(eHPz...)"`).
  Each spelling planted on the scratch copy's source and read RED by name by
  the arch binary (`red-4-lexical-plants.log` in the lane's out folder):
  a `pub` field, `pub const fn`, `pub async fn`, `pub unsafe fn`, `TryFrom`,
  `LowerHex`, `UpperHex`, `ToString`, `Display`, `Serialize`, `Hash` (an impl
  and a derive), `From<&SharedSecret>`, a seventh door, a door gone, a door
  back on `PublicKey`.
- **The bound.** The scan is lexical: it cannot see a type alias, a return
  type written `Self`, a signature or impl built by a macro, a re-export under
  another name, a door whose name holds neither word, or a forbidden impl in
  another file. Its header says so and no record claims more.

## Rows left (after the cut; named, not built)

- **A `KeyDeriverApi` implementor without an in-process key cannot return
  `SharedSecret`.** The type has no public constructor, so a deriver backed by
  an HSM or a remote signer that holds only the 33 ECDH bytes cannot build the
  trait's return value. No such implementor exists in the downstreams read.
- **`reveal_counterparty_secret(Anyone)` wraps a public value.** For
  `Counterparty::Anyone` the door returns the root's own public key as a
  `SharedSecret` (`src/wallet/key_deriver.rs`), so the redaction hides a value
  that is not secret. Stated or changed after the cut.
