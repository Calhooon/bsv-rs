`#[cfg(feature = "http")]`, which a doc test cannot gate, so it takes the
attribute and a `LISTED` row in `Error`'s words (the one entry added to a
list that otherwise only shrinks). 30 generated pins, 1 listed.

Closed (15), each row's reason in `CLOSED_ENUMS`. `WordCount`: BIP-39's five
sizes. `ExecutionContext`: a spend runs two scripts. `Word`: the node's two
flag words. `SignOutputs`: the three base hash types. `LockPosition`: before
or after. `Node`: a BUMP leaf is a hash or a duplicate flag. `Element`:
every outside match is exhaustive at a BEEF door, where a wildcard arm could
only skip an entry. `Step`, `Progress`, `Timed`: what one decoder call came
to, each handled by a driver loop. `TxDataFormat`: the frame's format byte
(`ts-stack@edf6e03` `packages/sdk/src/transaction/BeefConstants.ts:13-15`),
as `Element`. `BroadcastStatus`: success or error. `SecurityLevel`
(`packages/sdk/src/wallet/Wallet.interfaces.ts:225`,
`export type SecurityLevel = 0 | 1 | 2`) and `Counterparty`: permission code
matches them, and a wildcard arm would choose. `KeyringRevealer`: the
certifier or a key.

Held for row 4 (6), no attribute: both `Network`s (`src/compat/bip32.rs`,
`src/wallet/types.rs`), identity's `BroadcastResult`, overlay's `Protocol`,
