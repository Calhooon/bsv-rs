## The change

- `src/overlay/lookup_resolver/backoff.rs` (new, beside the parent under the
  ratchet's bound): `available_slap_trackers`, the trackers not backing off,
  `[]` for no trackers, else `Error::OverlayError("All SLAP trackers hosts are
  backing off for approximately <N>ms due to repeated failures.")`, N the
  soonest `backoff_until` less now; `has_available_host`, the reuse rule.
- `find_competent_hosts` takes its trackers from `available_slap_trackers`
  (the `?` refusal); `get_competent_hosts` reuses a fresh entry only when
  `has_available_host`. The refusal is not cached (the cache takes an answer
  only, as before). `No competent ...` stays in `query.rs` for trackers asked
  that named no host.
- Variant: `Error::OverlayError`, the resolver's host refusals' (no new
  variant).
