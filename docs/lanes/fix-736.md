(`git archive edf6e03 packages/sdk packages/wallet/wallet-toolbox/src`,

The large shapes name their sources by txid: the reference's
`Transaction.toBinary` over `sourceTransaction` links hashes the source
again for every input, so a 2048-input chain written that way took minutes;
with the ids computed once the recorder runs in under five seconds. The bytes
are the same either way (an input carries its source's txid alone).

`tests/support/identity_evidence_736.rs` rebuilds every BEEF with this
crate's writer; all six match the recorded SHA-256. The four bound shapes are
`Beef::to_binary` (the sorts agree). The two shapes of one parent written
twice are written by hand on both sides: no merge writes a txid twice
(`mergeRawTx` replaces, `mergeTxidOnly` returns the held entry; this crate's
`merge_raw_tx` and `merge_txid_only` the same), so the recorder sets `txs`
and calls `Beef.toWriter`, unsorted, and the builder pushes onto `txs` and
calls `Beef::to_writer`.
