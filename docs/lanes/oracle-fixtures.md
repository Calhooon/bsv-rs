# Lane oracle-fixtures: golden fixtures of the public surface (#76)

**Repository.** `bsv-rs`, your worktree on a branch from `origin/beta`. `docs/lanes/README.md` binds you. Four hours.

**Read in this order.** #76 and the epic #101 (the loop: a behavior PR changes its fixture in its own commit). `CLAUDE.md` rules 2, 3, 8. `src/wallet/wire/calls.rs` (`WalletCall`, the 28 calls), `src/wallet/wire/encoding.rs` (every request and result encoder and decoder), `src/wallet/wire/CLAUDE.md`; `src/wallet/substrates/http_json.rs` and `http_wire.rs` (the bodies per call; the error mapping, including `WalletBusy` from the body's word and `WalletTransport` for a bare 502, 503, 504, a connection error or a timeout, landed by #73 on `release/0.8.2` and in `beta` from its cut); `tests/wallet_wire_cross_sdk_tests.rs`, `tests/wire_method_roundtrip_tests.rs` and the 54 message files under `tests/vectors/wallet_wire/` (what already pins the wire: build on them, never duplicate them); `tests/wallet_http_json_busy_tests.rs` (wiremock driving the substrate); `src/transaction/beef.rs`, `beef_stream.rs`, `merkle_path.rs` and `tests/vectors/beef_of_any_size/` (the BEEF fixtures that exist); `tests/transaction/vectors/`. BRC-100 at the line's pin (`git -C ~/bsv/brcs show ed1b015:wallet/0100.md`; README rule 4 on the two pins) for every field name a fixture cites; BRC-62, BRC-74, BRC-95 for BEEF, BUMP and AtomicBEEF the same way. Two shapes are known to diverge from the BRC and are recorded as they are, never changed here: the certificate `certificateType` field and the nested hex key-linkage results (bsv-rs #105, a wire shape awaiting the keeper's and the owner's word). The CLI's wire fixtures (bsv-wallet-cli #69, `lane/oracle-fixtures` on its `origin/beta` when it has landed; the captain will name the path) cite the same pin: match its JSON shape where the two overlap so a diff across the crates is a `diff` of two files.

**The work.**
1. `tests/fixtures/`: one JSON file per surface, each entry a named input and the exact bytes out (hex) or the exact JSON body:
   - `wire/<call>.json`: for each of the 28 calls, the request encoding and the result encoding of at least one full and one minimal argument set, and every error frame the decoder can produce; recorded by this crate's own encoders (CLAUDE.md rule 2's fixture rule), cited to the BRC-100 section the call lives in.
   - `http_json/<call>.json`: the request body the substrate sends and the response body it reads, per call, plus one entry per error class (`WalletBusy` with and without `retry_after_ms`, `WalletTransport` for each of the five faults, a refusal body), recorded against wiremock.
   - `beef/`: BEEF v1 and v2, AtomicBEEF, a txid-only entry, each round-tripped by `Beef::from_binary` / `to_binary` and the streaming reader; `merkle_path/`: binary and hex; `transaction/`: serialization of the README's example transactions and the sighash vectors' transactions.
   Fields that must differ run to run (random keys, nonces, timestamps) are fixed by seeded inputs, never by a normalizer that hides bytes; say what each fixture seeds.
2. `tests/fixtures_replay.rs`: replays every file, fails on a byte of difference, printing the fixture's name, the field and the diff. `BSV_FIXTURES_RECORD=1` re-records and nothing else does. The count of fixtures by surface is pinned as a constant the test asserts (a fixture added or dropped moves it in its own commit).
3. The CI job `fixtures` in `ci.yml` (one job, `cargo test --features "full,http" --test fixtures_replay --locked`); you add the job, the captain adds the protection.
4. `docs/FIXTURES.md`: how to read a fixture, how a behavior PR changes one on purpose in its own commit, the BRC each surface cites and the pin.

**Bounds.** No change to any encoding or body: a fixture that reveals a disagreement with BRC-100 at the pin, or between the wire and the HTTP substrate, is recorded as found and named in the report, never fixed here. Nothing under `src/` except a `pub(crate)` test hook the recorder cannot do without, named in the report. `Cargo.toml` untouched (dev-dependencies are `oracle-benches`'s this wave; if you need one, say so and stop). Nothing under `tests/vectors/` is edited (CLAUDE.md rule 3).

**Report.** `REPORT: STATUS done|blocked`, the base and tip commits, the fixture count by surface and by call, every disagreement found with its BRC citation, the commands and their tails, the six tests each choice passes.
