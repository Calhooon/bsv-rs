## The rule

A required check that judges nothing is a claim CI makes and does not keep. On `beta` a pull request is held to `--release-type minor` (an addition passes; a break cargo-semver-checks 0.51.0 has a lint for fails: a removed or renamed item, a changed parameter count or receiver and the like; a break it has no lint for, a changed parameter type or a changed return type beyond a value gained or lost among them, passes it, so a green check is no evidence for such a change, which stays the reads' to judge) unless it carries the `api-break` label, read live before the check. No SDK behaviour, wire byte, verdict or error text moves; no row of the root `CLAUDE.md` divergence list is touched, and no cell of `src/transaction/CLAUDE.md` moves.
