## A finding against the brief

The brief asked the agreeing copy to replace the lying one "in its place
(the answer's order unchanged)". The recording shows the reference answers
`[B, A honest]` for a liar answering `[A lying, B]` ahead of an honest
`[A]`: it drops the lying `A` and keys the honest one when it arrives. In
place would answer `[A honest, B]`, a second stated cell. The brief also
asked that the port equal the reference on every shape but the lone liar,
and rule 1 says the reference decides, so the agreeing copy stands where it
arrived: this crate's answer less its kept lying outputs is the reference's,
copies and order while the hosts answer in rank order (the cold read's
probe: with the host ranked ahead delayed 50 ms the reference answers
`[A honest, B]` and this crate `[B, A honest]`, its merge in rank order
after `join_all`, the reference's in completion order, `:1501-1502`; older
than #796). The test kept the brief's name until the reads' fold renamed
it for what it asserts, the reference's order:
`an_agreeing_copy_displaces_a_liar_and_stands_where_it_arrived_796`.

The brief's residue (a binary aggregated answer's outputs each carrying the
whole BEEF) is closed already at this base by #735's fold
(`facilitators/binary_answer.rs`). A JSON host serving one multi-transaction
BEEF for an output of a transaction other than the BEEF's subject is judged
by the subject on both sides (`:2233`), so it is the stated cell, not a
residue of its own.
