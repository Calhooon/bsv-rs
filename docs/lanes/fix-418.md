# #418: the default mode reads the transaction version unsigned; a word keeps the node's `int32_t`

Base `7a047467` (`origin/beta`'s tip at the lane's start, 2026-11-09; the brief was read at `e228c61a`).

## The decision

The default mode is the reference's: `ts-stack@edf6e03` reads the version with
`readUInt32LE` (`Transaction.ts:471`) and relaxes at `transactionVersion > 1`
(`Spend.ts:319-321`), so 0x80000000 and 0xFFFFFFFF are relaxed. A word is the
node's: bitcoin-sv v1.2.2 holds `int32_t nVersion` (`transaction.h:273`) and
`IsMalleableTxnVersion` compares it signed (`interpreter.cpp:34-44`); go-sdk at
`2ca481c` converts to `int32` (`thread.go:513-518`). The reference's explicit
flags apply the unsigned comparison (`Spend.ts:343-345`): the reference
diverging from consensus, a filing draft
(`375-filings/transaction-version-sign-ts-stack.md`, queue row 29).
