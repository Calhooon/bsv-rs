  mismatch at the reference's `sign` and `verify`. Here `verify` names the
  output ahead too (in this crate's older words, `Input N source output index

  for an input with a template). Stated.

  `unlockingScript is undefined`; here the mismatch. Stated.
- An earlier input's failing script and a later input's mismatch: the
  reference names the script; this crate's `verify` reads every input's source
  before it runs a script and names the mismatch. Stated.
- A mismatch and a linked source output whose amount is absent or past 21e14
  (the cold read of PR #901, run on both sides, not in the recording): the
  reference's `sign` and `verify` name the amount (`Input N source amount must
  be a non-negative safe integer no greater than 21e14.`, `:969`,
  `:1418-1422`, ahead of the comparison); here `sign` names the mismatch (it
  reads no source amount before its pass). Stated. At `verify` both name the
  amount since the fold (recorded, `absent_source_amount_and_mismatch`).
