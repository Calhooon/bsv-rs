The issue's correction: it reads a re-serialization at `merge_raw_tx`. On beta
the parse keeps the bytes (`Transaction::from_binary` sets `raw_bytes_cache`,
`transaction.rs:180-187`) and `to_binary` returns a clone of them
(`:1373-1381`), so the held bytes are hashed; the waste was one `sha256d` and
one clone of the body per merged raw entry, while the source entry holds its
txid already.

## Why the source's txid is the hash

`BeefTx::with_txid` is `pub(crate)`. Its callers in `src/` at `c96f3c7e`:

1. `src/transaction/beef.rs:386` `push_transaction`: the txid its caller computed from the transaction it passes (`t.id()` in `merge_beef`; the collected ancestors' ids in `to_beef`).
2. `src/transaction/beef.rs:396` `merge_raw_tx`: the hash of the bytes it was given (now through `store_raw_entry`, `merge_entry.rs`).
3. `src/transaction/beef/collect.rs:173`: the decoder's hash of the bytes it read.
4. `src/transaction/beef/merge_graph.rs:57`: `tx.id()` of the transaction stored.

On the tip a fifth site, `merge_entry.rs`'s `store_raw_entry`, is the body
callers 2 and the new door share. A source entry on `merge_beef`'s raw branch
holds bytes; its `txid` is one of those hashes of them, or `None`, and then
`txid()` hashes them (or the parse of them). An entry mutated through `tx_mut`
dropped its bytes and txid (`beef_tx.rs:211-219`) and takes the parsed branch,
`push_transaction(t.id(), ..)`, unchanged. So in every reachable state the
txid passed is the one `merge_raw_tx` would compute.

## The pre-pass (lane fix-621-prepass, after #817)

Opened from `origin/lane/fix-817-beef-writers` at `b8c368e9` (PR #836's head,
one commit on beta `6a9dde3c`); `git rev-parse HEAD` was `b8c368e9`, no reset.

PR #836 made `merge_beef` give the reference snapshot's verdict by the literal
round trip (write the source in its merge order, `Beef::from_binary` of the
bytes), about twice the merge's cost. The ensemble allowed a pre-pass in its
place if its verdict is proven equal to the round trip's on every BEEF the
tree's vectors hold and on a fuzz target.

### The reader's refusal sites, and how the pre-pass answers each

`Beef::from_binary` is `collect` (`beef/collect.rs`) over the streaming
decoder in its collect mode. On the bytes the snapshot writes after the
writers' check (`check_writable_in`, unchanged):

| Site | Reached after the check? | The pre-pass |
|---|---|---|
| version word (`check_version`, `BadVersion`), the Atomic prefix | no: the check refuses a word other than V1 or V2, the snapshot writes no prefix | the check |
| `NBumps`, `NTxs`, `BadVarint`, `Truncated` on a count | no: the writer's varints | none needed |
| BUMP: `TreeHeightOver64`, `TreeHeightZero` (height byte) | yes (65 to 255 levels, no levels: written, #817's rows) | `Bump::read_alone` on the BUMP's written bytes |
| BUMP: `OffsetOutsideTree`, `DuplicateOffset` (offset varint) | yes | `Bump::read_alone` |
| BUMP: `BadFlag` (leaf flag) | no: the writer writes `00`, `01`, `02` (a duplicate flagged txid refused by the check) | `Bump::read_alone` (would answer it) |
| BUMP walk (`bump_root`): `NoTxidAtLevelZero`, `MissingSibling`, `MismatchedNode`, `LeftDuplicateBelow`, `OffsetOutsideTree` at the top | yes | `Bump::read_alone` (the decoder's `next_leaf` calls `bump_root`) |
| BUMP height above a `u32` (`in_memory`, `RootNotCarried`) | no: `MerklePath.block_height` is a `u32` | `in_memory_bump`, called as `collect` calls it |
| the judge's `fold_bump`: `RootNotCarried` for a BUMP whose root a leading BUMP of its height contradicts | yes, but returned only beside a later refusal of the bytes | the same `Judge`, folded in `collect`'s order, its `refuse` naming it ahead of a later BUMP's refusal |
| `V2Format`, `V1Has` flags, `StubTxid` | no: the writer writes 0, 1, 2 and 0, 1; a txid-only txid is 64 hex digits (checked) | none needed |
| a transaction's fields (`Truncated`, `BadVarint`, `TrailingBytes` after the frame) | no: every entry's written bytes are checked by `one_transaction`, which takes exactly the bytes `Transaction`'s reader takes (`a_frame_the_scan_accepts_is_the_one_the_parser_reads_817`): the bytes held, else a parsed transaction's cached serialization (`Transaction::from_binary` caches the whole buffer it read a prefix of, #840), else none, a serialization of the fields one transaction by construction (until the fold a parsed entry was taken on trust: the cold read's finding, the fold below) | the check |
| `Transaction::from_binary` in `collect_element` | no, the same | the check |
| the decoder's deferred content refusals (`check_transaction`: unproven coinbase, no input, no output, value, null or repeated outpoint) and the judge's entry folds (`BumpIndexNamesNoBump`, `TxidNotInBump`, ...) | collected, never returned: `collect` returns the judge's refusal only beside a later refusal of the bytes, and no entry's bytes give one | none needed |
| `finish` at the frame's end | no: the frame ends where the writer ends it | none needed |

No state takes the slow path: every refusal the reader can raise after the
check is a BUMP's, and each is the reader's own function on the BUMP's
bytes (no rule written twice). The pre-pass is `Beef::bumps_as_read`
(`beef/collect.rs`); `snapshot_verdict` is the check then it.
