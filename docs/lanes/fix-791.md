## The word

> a heavy hosted run (a complete mutation run, a nightly) takes up to fourteen
> of the twenty slots inside its own window when no other heavy run of the
> account is scheduled in that window, six otherwise.

  word names a nightly a heavy run, so the incremental night takes the same
  rule: `NIGHT_PARALLEL` is gone, not kept at six.

- Docs: `docs/NIGHTLY.md` (the rule, the table, the input, the owner #675,
