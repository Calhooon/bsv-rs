The orders differ within ASCII (Node's `localeCompare`: `a_b, a0, age, éa, f, Name`; bytes: `Name, a0, a_b, age, f, éa`), so for such names a signature made here fails in the reference and the reference's fails here. BRC-52 at `5119a9b` (`~/bsv/brcs`, `0052.md:99-103`): the order is "host-dependent collation, not UTF-8 byte ordering"; "an implementation reconstructing the preimage MUST reproduce the issuer's field order and exact encoded field text.
