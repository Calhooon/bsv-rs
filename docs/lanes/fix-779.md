## The new tests

`tests/lookup_discovery_779.rs`, on the public API (`LookupResolver::new`,
`LookupResolverConfig`, `find_competent_hosts`, `query`, `NetworkPreset`). A
scripted facilitator answers by URL (a URL outside the script refused in
`unscripted: <url>`) and records each question's URL, service and query; the
advertisements are signed by this crate's writer
(`create_signed_overlay_admin_token`) and wrapped by
`support/pushdrop_lock_position_537.rs`'s `output_of`. Every tracker is an
`.invalid` name or a URL the facilitator never dials.

- `find_competent_hosts_answers_the_hosts_a_scripted_tracker_names`: a tracker
  advertising `https://one.discovery-779.invalid` and
  `https://two.discovery-779.invalid`, a second tracker answering a scripted
  refusal; the hosts sorted equal the two (the discovery gathers into a
  `HashSet`, `lookup_resolver.rs:347`, so the order is not the tracker's and
  is not pinned); the record exactly the two trackers each asked once with
  `ls_slap` and `{"service": "ls_test_service"}`.
- `find_competent_hosts_sends_an_empty_service_as_given`: the record exactly
  the tracker with `{"service": ""}`; the tracker's advertisement for
  `ls_test_service` is no answer for `""`, so `Ok([])`.
- `find_competent_hosts_on_the_local_preset_asks_its_tracker`:
  `NetworkPreset::Local.slap_trackers() == ["http://localhost:8080"]`; the
  record exactly that URL with `{"service": "ls_test"}`, and the advertised
  host returned. The advertised host is `https://`: the admin token's URI check
  (`admin_token_validation.rs:26-30`) refuses `http://`, the first draft's
  `http://` host answering `[]`.
- `find_competent_hosts_does_not_apply_a_host_override`: the override names
  `https://override.host`, the tracker advertises `https://discovered.host`;
  the discovery answers `["https://discovered.host"]`, the record the tracker
  alone; then `query` on the same resolver (the internal `get_competent_hosts`)
  asks `https://override.host` alone, with the service and `{}`, and returns
  its empty output list.
