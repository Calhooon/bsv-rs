# #739: the subject filter at `discover_certificates` and `discover_certificates_by_type`

Base `13cd2c74` (`origin/beta`'s tip at the lane's start, #738 landed: the
subject filter at `resolve_by_identity_key`). From the scoped cold re-read of
PR #738 (#737, 2026-11-04 03:4xZ).

## The rule

`discover_certificates(identity_key)` is this crate's door for the BRC-100
wallet's `discoverByIdentityKey` (`ts-stack@edf6e03`
`packages/sdk/src/wallet/Wallet.interfaces.ts:989-1001,1296-1299`; the toolbox's
`Wallet.ts:966-1015`), the path whose parsers this crate ports (#553, #730,
#737; the rule read of PR #742 corrected the lane's "no counterpart"): a by-key
discovery returns the asked key's certificates, as
`filterCertificatesByIdentityKey` keeps them on that path
(`packages/wallet/wallet-toolbox/src/utility/identityUtils.ts:247-255`,
`certificate.subject.toLowerCase() === identityKey.toLowerCase()`, called at
`Wallet.ts:1012`): a parity rule. What that door does beyond it (the query
shape, the trust step, the page, the argument check, the contact shortcut, the
result type) is the CHANGELOG entry's parity note. `discover_certificates_by_type`
has no counterpart (`DiscoverByIdentityKeyArgs` carries no type); the
certificates' type is not checked here (#744).

## The code

- `is_asked_subject(subject, identity_key)`, private in `src/identity/client.rs`:
  the subject's compressed hex against the asked key lower-cased; the one
  comparison of `resolve_by_identity_key` and the two `discover_*` doors. No
  public item.
- `discover_of_subject(identity_key, query)`, private: the two doors' shared
  walk, unchanged otherwise (every output parsed in order through
  `parse_output_to_verifiable_certificate`, a skip passed over, a `limit`
  anywhere the call's `Err`), then the filter. `query` and
  `resolve_by_attributes` are unchanged.

## Semver

A behaviour change at two public doors without a signature change:
`discover_certificates` and `discover_certificates_by_type` drop a
certificate whose subject is not the asked key, where they returned it.
Migration: none.
