## The witness

`tests/support/identity_beef_subject_728.mjs` copies #725's helpers and uses
its bundle recipe (`git archive edf6e03 packages/sdk
packages/wallet/wallet-toolbox/src`, #553's tsconfig, `parseEvidence`

The transactions are #725's. The shapes are written by the reference's own
writers: `Beef.toBinary` keeps a txid-only entry merged after a proven raw one
last (no hand bytes for shape 2), `toBinaryAtomic` of a txid-only subject keeps
it alone, and `mergeRawTx` keeps an explicit BUMP index. One Atomic BEEF prefix
is written by hand before `Beef.toBinary`'s bytes, as #725's absent header was,
so the token's transaction sits beside the txid-only subject. For each BEEF the
recorder writes the bytes, the output index, the wire order, `parseEvidence`'s
pick or refusal, the refusing line (replayed through `Beef`'s public methods,
now with the `:126` index check) and `parseResults`' outcome. Two runs are
byte-identical. #725's vector is untouched.

This crate's writer builds every recorded BEEF byte for byte (`to_binary`,
`to_binary_atomic`, the one prefix written by hand on both sides); shape 1's
bytes equal #725's `chain`.
