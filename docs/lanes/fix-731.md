## The collect mode's answer

The issue asked whether `Beef::from_binary`'s collect mode reorders a
repeated txid's entries. By reading, no: `collect.rs`'s loop pushes each
element as the decoder yields it (`collect_element`, `push_tx`), the
decoder's `finish` checks framing alone, and the atomic graph walk is the
stream judge's. Pinned by the unit module's wire-order assertion (each
parsed entry's txid, txid-only flag and BUMP index equal to the recorded
`wire_order`).
