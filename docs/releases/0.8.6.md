# bsv-rs 0.8.6

## In short

- **`Signature::from_der` read malformed encodings of a valid signature as that signature** (bytes after it, a wrong sequence length, an unneeded zero), so one signature verified under many byte forms at `messages::verify`, `compat::bsm::verify_message_der`, `Certificate::verify`, `ProtoWallet::verify_signature` and the KVStore interpreter. These forms are refused now. Nothing could be forged: no form verifies over other data. Advisory [GHSA-9c8r-76f3-m426](https://github.com/Calhooon/bsv-rs/security/advisories/GHSA-9c8r-76f3-m426), Medium (5.3). #842
- **`Transaction::from_json` accepted an input txid that is not 64 hex digits** and wrote that input as spending the txid of 32 zero bytes. Such a txid is refused now. Advisory [GHSA-84xq-3662-pvx5](https://github.com/Calhooon/bsv-rs/security/advisories/GHSA-84xq-3662-pvx5), Medium (5.3). #845
- **The script interpreter reads a signature as the node does under a flag word.** Of 1,020 cells, 0.8.5 refused 12 scripts that 0.8.6 accepts and accepted none that 0.8.6 refuses. #847
- **`fee(.., ChangeDistribution::Random)` over two or more change outputs**, with a change of 2 satoshis or more, panicked in a debug build and, in release, wrote 0 to every change output but the last. #868

No public type or signature changes.

## Not changed

- A signature still has a second encoding that verifies, its high-S form; `Signature::is_low_s()` tells them apart.
- An input built with `TransactionInput::new` from a txid text that is not 64 hex digits is still written as the zero txid.
- The 0.9.0 prereleases published so far (0.9.0-beta.1 to 0.9.0-beta.7) are affected by both advisories; the next prerelease carries the fixes.

## How it was checked

- Each fix was red on `main` before it and green after, by three independent reads; on `beta`, bsv-script-lean, a Lean specification of bitcoin-sv's script interpreter, shows no divergence on the 13,765 script entries of its corpora, less the pre-Genesis ones it has no word for, before or after.
- Every sentence of this release's changelog section and of both advisories that says what a version does was run on the crates as crates.io serves them; the ranges were swept over all 60 published versions.
